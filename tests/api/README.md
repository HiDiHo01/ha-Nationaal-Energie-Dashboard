# API-tests

Test de onafhankelijke NED-library met gemockte HTTP-responses, inclusief authenticatie, parsing, paginering, retries, rate limiting, cancellation en DST. Live contracttests zijn opt-in; gebruik veilig geïnjecteerde credentials.

De eerste synthetische tests in [test_exceptions.py](test_exceptions.py) toetsen alle acht specifieke exceptiontypes en de gemeenschappelijke basis. Draai de gelockte baseline vanuit de repository-root met `uv run --locked pytest tests/api --cov=ned_api --cov-branch --cov-report=term-missing`; de volledige baseline-CI blijft leidend voor alle coveragepoorten.

De [transporttests](test_transport.py) gebruiken een gemockte aiohttp-sessie, async responsecontext en synthetische streamingchunks. Zij toetsen statusbehoud, veilige requestopties, validatie van origin/pad/limieten, responsegrootte, encoding, gesloten sessie, geschoonde fouten en cancellation. Lokale synthetische tests op Python 3.13.5/aiohttp 3.13.3/yarl 1.24.2: 47 geslaagd (9 bestaande, 38 nieuwe), 71 statements en 18 branches volledig gedekt (100%), compileall geslaagd. SHA's van de geteste bron- en testbestanden gecontroleerd tegen Git-tree. De exacte productie-baseline 3.14.10/aiohttp 3.14.5/yarl 1.25.1, gelockte Ruff/Pylint/mypy en wheelvalidatie wachten op CI. Geen live requests, echte TLS-handshake of gemeten timeoutduur; de tests controleren configuratie en gesimuleerde foutpaden.

# Bijdragen

Bespreek voorgestelde wijzigingen met de eigenaar via een issue. Volg [AGENTS.md](AGENTS.md) en [AI_POLICY.md](AI_POLICY.md). Projecteigen bijdragen worden aangeboden onder [GPL-3.0-only](LICENSE). Draag alleen materiaal bij waarvoor je de benodigde rechten hebt; behoud licentie- en auteursrechtvermeldingen van derden. De interne reviewprocedure beperkt geen rechten onder de GPL.

Richt de gelockte ontwikkelomgeving en pre-commit in volgens [DEVELOPMENT.md](docs/DEVELOPMENT.md#pre-commit-en-vs-code). Werk via pull requests en voer vóór iedere commit de toepasselijke hooks uit. De verplichte Baseline CI herhaalt deze controles.

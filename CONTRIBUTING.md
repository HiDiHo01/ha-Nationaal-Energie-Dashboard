# Bijdragen

Bespreek voorgestelde wijzigingen met de eigenaar via een issue. Volg [AGENTS.md](AGENTS.md) en [AI_POLICY.md](AI_POLICY.md). De [gebruiksvoorwaarden](USAGE_TERMS.md) verlenen geen algemene rechten voor afgeleide projecten. Spreek zo nodig vooraf de rechten voor een bijdrage af.

Richt de gelockte ontwikkelomgeving en pre-commit in volgens [DEVELOPMENT.md](docs/DEVELOPMENT.md#pre-commit-en-vs-code). Werk via pull requests en voer vóór iedere commit de toepasselijke hooks uit. De verplichte Baseline CI herhaalt deze controles.
